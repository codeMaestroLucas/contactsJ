# Prompt WebScrapping Java

**Contexto**: Geração de classes Java (Selenium/Apache POI) para web-scraping de sites de advocacia baseados nas classes abstratas ByPage e ByNewPage.

---

## 1. Estrutura Obrigatória do Output

O output deve conter **apenas** os seguintes itens, nesta ordem:

1. **Touch**: Uma única linha `touch` para criar todos os arquivos no diretório correto.
2. **Firmas**: Código completo dos scrapers em blocos separados, ordenados alfabeticamente.
3. **Builders**: Código de instanciação das firmas, agrupadas por Tipo e Continente (máx. 5 por linha).

**Diretórios por continente:**
- Africa:   `core/src/main/java/org/example/src/sites/to_test/africa`
- Americas: `core/src/main/java/org/example/src/sites/to_test/americas`
- Asia:     `core/src/main/java/org/example/src/sites/to_test/asia`
- Europe:   `core/src/main/java/org/example/src/sites/to_test/europe`
- Oceania:  `core/src/main/java/org/example/src/sites/to_test/oceania`

---

## 2. Lógica das Classes

- **ByPage**: Extração direta dos elementos da lista.
- **ByNewPage**: Obrigatório usar `this.openNewTab(lawyer)` dentro de `getLawyer`. Sempre prefira coletar dados disponíveis na primeira página antes de abrir nova aba.

```java
// CORRETO - dados da 1ª página extraídos antes do openNewTab
protected Object getLawyer(WebElement lawyer) throws Exception {
    String name = extractor.extractLawyerText(lawyer, new By[]{By.tagName("h3")}, "NAME", LawyerExceptions::nameException);
    String role = extractor.extractLawyerText(lawyer, new By[]{By.className("gdlr-core-title-item-caption")}, "ROLE", LawyerExceptions::roleException);

    // Bem como outros dados que puderem ser coletados na 1ª página

    String link = this.openNewTab(lawyer);
    WebElement container = driver.findElement(By.className("gdlr-core-pbf-column-content"));

    return Map.of(
            "link", link,
            "name", name,
            ...
    );
}
```

## 3. Regras de Implementação

### 3.1 Package

O package deve corresponder ao diretório de destino:
- `package org.example.src.sites.to_test;`
- `package org.example.src.sites.to_test.africa;`
- `package org.example.src.sites.to_test.americas;`
- `package org.example.src.sites.to_test.asia;`
- `package org.example.src.sites.to_test.europe;`
- `package org.example.src.sites.to_test.oceania;`

### 3.2 Filtro de Roles

**Role disponível na 1ª página** (elemento `lawyer` da listagem) → usar `filterLawyersInPage` em `getLawyersInPage()`:
```java
@Override
protected List<WebElement> getLawyersInPage() {
    List<WebElement> lawyers = MyDriver.wait.findElements(By.cssSelector("..."));
    return this.siteUtl.filterLawyersInPage(lawyers, new By[] {By.cssSelector("...")}, true);
}
```

**Role disponível apenas na 2ª página** (extraída de `container` ou `driver.findElement`) → usar `isValidPosition` em `getLawyer()`, logo após extrair a role:
```java
String role = extractor.extractLawyerText(container, new By[]{By.cssSelector("...")}, "ROLE", LawyerExceptions::roleException);
if (!siteUtl.isValidPosition(role, validRoles)) return "Invalid Role";
```

> Use `private final By[] byRoleArray = { By.cssSelector("") };` como campo de classe **apenas** quando o seletor de role for reutilizado em outros métodos além de `getLawyersInPage`.

### 3.3 Extração de Dados

- Usar a instância `extractor` (`extractor.extractLawyerText(...)`) com lambdas de `LawyerExceptions` — nunca lambdas vazias `(e) -> ""`.
- Preferir `getSocials()` (com `true` para texto individual, `false` para href) ou `getSocialsFromText()` para coletar email e telefone.
- Usar `super.getSocials` onde possível.
- O parâmetro `WebElement` em `getLawyer` e auxiliares deve se chamar **obrigatoriamente** `lawyer`.
- `extractLawyerText` deve receber um `WebElement` container, nunca diretamente o `driver`.

### 3.4 Utilitários e Formatação

- Preferir funções de `SiteUtils.java` e `Site.java`.
- Para strings: `TreatLawyerParams.treatName(name)` e `treatNameForEmail(name)`.
- Telefones: `"phone", socials[1].isEmpty() ? "xxxx" : socials[1]` — substituir `"xxxx"` pelo telefone da firma se encontrado.
- Indentação do `super()`: argumentos com um nível a menos que o padrão.
- Sempre usar `MyDriver.wait` — nunca criar `WebDriverWait` local.
- Sempre capturar o retorno de `openNewTab`: `String link = this.openNewTab(lawyer);`.
- `By[]` inline nos extractors — nunca declarar como variáveis externas.


### 3.5 Construtor

Utilize o construtor da seguinte forma:
```java
    public FirmA() {
        super(
                "Frim A",
                "siteLink",
                1
        );
    }
```

### 3.6 ByNewPage — `openNewTab` obrigatório

Todo `getLawyer` de uma classe ByNewPage **deve** chamar `this.openNewTab(lawyer)` e sempre capturar o retorno em `link`:

```java
String link = this.openNewTab(lawyer);
```

A ausência dessa chamada invalida a classe. A captura do retorno é obrigatória mesmo que `link` não seja incluído no `Map` final.

## 4. Modelo do Builder

Os builders estão em `firms/src/main/java/org/example/src/utils/myInterface/` (`ByNewPageFirmsBuilder.java` e `ByPageFirmsBuilder.java`).

- Continentes (exceto Americas): comentário `// ByPage - <Continente>` ou `// ByNewPage - <Continente>`.
- Americas: array único, subdividido internamente em `// North America`, `// Central America`, `// South America`.
- Máximo 5 firmas por linha.

```java
// ByPage - Africa

new FirmaF(),

new FirmaG(),


// ByNewPage - Americas
// Central America
new FirmaCA1(),

// South America
new FirmaSA2(), new FirmaSA3(),
```

```java

protected Object getLawyer(WebElement lawyer) throws Exception {
    this.openNewTab(lawyer);
    WebElement content = driver.findElement(By.className("col-md-12"));

    String role = extractor.extractLawyerText(container, new By[]{By.("")}, "ROLE", LawyerExceptions::roleException);
    if (!siteUtl.isValidPosition(role, validRoles)) return "Invalid Role";

## 6. VCard

> **Use `VCard` apenas quando explicitamente solicitado nos dados da firma.** Nunca o inclua por padrão ou especulativamente.

Declare como campo privado da classe:

```java
// Padrões padrão — funciona para a maioria dos sites
private final VCard vCard = VCard.withDefaultPatterns();

// — ou — padrões customizados quando o site usa estrutura não-padrão
private final VCard vCard = new VCard(
    "X-EMAIL[^:\\r\\n]*:([^\\r\\n]+)",
    "X-TEL[^:\\r\\n]*:([^\\r\\n]+)"
);
```

Dentro de `getLawyer`, obtenha o `href` do link `.vcf` e chame `getSocials`:

```java
String vcardHref = lawyer.findElement(By.cssSelector("a.vcard")).getAttribute("href");

// Endpoint público (sem necessidade de sessão do browser):
String[] socials = vCard.getSocials(vcardHref);

// — ou — quando o endpoint exige cookies da sessão ativa:
String[] socials = vCard.getSocials(driver, vcardHref);

String email = socials[0];
String phone  = socials[1];
```

Retorna `String[]{ email, phone }` — strings vazias quando não encontrado.

## 7. Anti-padrões — Checklist Interno

> Antes de gerar cada classe, verificar todos os itens abaixo.

| # | Anti-padrão | Correção |
|---|---|---|
| 1 | Dados na subpágina quando disponíveis na 1ª (ByNewPage) | Extrair da 1ª página antes de chamar `openNewTab` |
| 2 | `this.openNewTab(lawyer)` sem capturar retorno | `String link = this.openNewTab(lawyer);` |
| 3 | Classe ByNewPage sem chamada a `this.openNewTab(lawyer)` em `getLawyer` | Toda classe ByNewPage **deve** chamar `openNewTab` — ver seção 3.6 |
| 4 | `new WebDriverWait(this.driver, Duration.ofSeconds(10))` | `MyDriver.wait.findElements(...)` |
| 5 | Lambda vazia `(e) -> ""` em `extractLawyerText` ou `extractLawyerAttribute`  | `LawyerExceptions::socialsException` (ou equivalente) |
| 6 | `By[] nameBy = {...}` declarado fora e passado como variável | `new By[] {...}` inline dentro do extractor |
| 7 | `extractor.extractLawyerText(driver, ...)` direto no driver | `WebElement container = driver.findElement(...);` → `extractor.extractLawyerText(container, ...)` |
| 8 | `VCard` incluído sem ser solicitado nos dados da firma | Remover — `VCard` só é usado quando explicitamente pedido (ver seção 6) |
