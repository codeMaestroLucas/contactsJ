# Prompt WebScrapping Java

**Contexto**: Geração de classes Java (Selenium/Apache POI) para web-scraping de sites de advocacia baseados nas classes abstratas ByPage e ByNewPage.

---

## 1. Estrutura Obrigatória do Output

O output deve conter **apenas um único bloco bash** que, ao ser executado, cria todos os arquivos com seu conteúdo.

Formato do bloco:

```bash
cat > <caminho>.java << 'EOF'
<código completo da firma>
EOF

cat > <caminho2>.java << 'EOF'
<código completo da firma 2>
EOF
```

Regras do bloco único:
- Use `cat >` para criar/sobrescrever arquivos `.java` (cria o arquivo e insere o conteúdo).
- Firmas ordenadas **alfabeticamente** dentro do bloco.
- **Não** incluir `touch`, blocos de código avulsos, comentários explicativos ou qualquer texto fora do bloco bash.

**Diretórios por continente:**
- Africa:   `firms/src/main/java/org/example/src/sites/africa`
- Americas: `firms/src/main/java/org/example/src/sites/americas`
- Asia:     `firms/src/main/java/org/example/src/sites/asia`
- Europe:   `firms/src/main/java/org/example/src/sites/europe`
- Oceania:  `firms/src/main/java/org/example/src/sites/oceania`

## 2. Lógica das Classes

- **ByPage**: Extração direta dos elementos da lista.
- **ByNewPage**: Obrigatório usar `this.openNewTab(lawyer)` dentro de `getLawyer`. Sempre prefira coletar dados disponíveis na primeira página antes de abrir nova aba.

```java
// CORRETO - dados da 1ª página extraídos antes do openNewTab
protected Object getLawyer(WebElement lawyer) throws Exception {
    String name = extractor.extractLawyerText(lawyer, new By[]{By.tagName("h3")}, "NAME", LawyerExceptions::nameException);
    String role = extractor.extractLawyerText(lawyer, new By[]{By.className("gdlr-core-title-item-caption")}, "ROLE", LawyerExceptions::roleException);

    // Bem como outros dados que puderem ser coletados na 1ª página

    String link = this.openNewTab(lawyer);
    WebElement container = MyDriver.wait.findElement(By.className("gdlr-core-pbf-column-content"));

    return Map.of(
            "link", link,
            "name", name,
            ...
    );
}
```

## 3. Regras de Implementação

### 3.1 Package

O package deve corresponder ao diretório de destino:
- `package org.example.src.sites.africa;`
- `package org.example.src.sites.americas;`
- `package org.example.src.sites.asia;`
- `package org.example.src.sites.europe;`
- `package org.example.src.sites.oceania;`

### 3.2 Filtro de Roles

**Role disponível na 1ª página** (elemento `lawyer` da listagem) → usar `filterLawyersInPage` em `getLawyersInPage()`:
```java
@Override
protected List<WebElement> getLawyersInPage() {
    List<WebElement> lawyers = MyDriver.wait.findElements(By.cssSelector("..."));
    return this.siteUtl.filterLawyersInPage(lawyers, new By[] {By.cssSelector("...")}, true);
}
```

**Role disponível apenas na 2ª página** (extraída de `container` ou `driver.findElement`) → usar `isValidPosition` em `getLawyer()`, logo após extrair a role:
```java
String role = extractor.extractLawyerText(container, new By[]{By.cssSelector("...")}, "ROLE", LawyerExceptions::roleException);
if (!siteUtl.isValidPosition(role, validRoles)) return "Invalid Role";
```

> Use `private final By[] byRoleArray = { By.cssSelector("") };` como campo de classe **apenas** quando o seletor de role for reutilizado em outros métodos além de `getLawyersInPage`.

### 3.3 Utilização Correta de Funcionalidades

#### 3.3.1 LawyerExceptions — referência completa

Cada campo do `Map` final possui seu método de exception correspondente. **Nunca** use lambda vazia `(e) -> ""` — sempre passe o método adequado ao campo extraído:

| Campo extraído | Method reference |
|---|---|
| link | `LawyerExceptions::linkException` |
| name | `LawyerExceptions::nameException` |
| role | `LawyerExceptions::roleException` |
| country | `LawyerExceptions::countryException` |
| practice_area | `LawyerExceptions::practiceAreaException` |
| email | `LawyerExceptions::emailException` |
| phone | `LawyerExceptions::phoneException` |
| socials (genérico) | `LawyerExceptions::socialsException` |

#### 3.3.2 extractLawyerText e extractLawyerAttribute

Ambos recebem: `(WebElement container, By[] locators, String fieldName, Function<String, LawyerExceptions> exceptionSupplier)`.

```java
// Texto — usa getText()
String name = extractor.extractLawyerText(lawyer, new By[]{By.cssSelector("h3.name")}, "NAME", LawyerExceptions::nameException);

// Atributo — usa getAttribute(attrName)
String link = extractor.extractLawyerAttribute(lawyer,new By[]{By.tagName("a")},"LINK","href",LawyerExceptions::linkException);

// Navegação aninhada via array de locators
String role = extractor.extractLawyerText(lawyer,new By[]{By.className("info"), By.cssSelector("span.role")},"ROLE",LawyerExceptions::roleException);
```

Regras obrigatórias:
- O primeiro argumento é sempre um `WebElement` container — **nunca** passar `driver` diretamente.
- Os `By[]` são declarados **inline** — nunca como variáveis externas (exceto `byRoleArray`, quando reutilizado em outro método além de `getLawyersInPage`).
- O parâmetro `WebElement` em `getLawyer` e auxiliares deve se chamar **obrigatoriamente** `lawyer`.

#### 3.3.3 getSocials e getSocialsFromText

Retornam sempre `String[]{ email, phone }` — strings vazias quando não encontrado.

```java
// getSocials — a partir de uma lista de WebElements (links/textos da página)
// true  → usa getText() de cada elemento
// false → usa getAttribute("href") de cada elemento
String[] socials = this.getSocials(container.findElements(By.cssSelector("a.contact")), true);

// super.getSocials — delega ao Site.java (preferível quando disponível)
String[] socials = super.getSocials(lawyer);

// getSocialsFromText — a partir de texto bruto (HTML ou texto corrido)
String rawText = container.getAttribute("innerHTML");
String[] socials = this.getSocialsFromText(rawText);

String email = socials[0];
String phone = socials[1];
```

Preferência: `super.getSocials` > `getSocials(list, bool)` > `getSocialsFromText`.

#### 3.3.4 Formatação de strings para uso em emails

```java
// Gera versão do nome adequada para compor e-mail
String emailName = TreatLawyerParams.treatNameForEmail(name);
```

#### 3.3.5 Regras operacionais

- **Telefone fallback**: `"phone", socials[1].isEmpty() ? "xxxx" : socials[1]` — substituir `"xxxx"` pelo número fixo da firma quando conhecido.
- **WebDriverWait**: sempre usar `MyDriver.wait` — nunca instanciar `new WebDriverWait(driver, ...)` local.
- **openNewTab**: sempre capturar o retorno — `String link = this.openNewTab(lawyer);`.
- **Indentação do `super()`**: argumentos com um nível a menos que o padrão do arquivo.
- Preferir funções de `SiteUtils.java` e `Site.java` antes de implementar lógica própria.


### 3.4 Construtor

Utilize o construtor da seguinte forma:
```java
    public FirmA() {
        super(
                "Frim A",
                "siteLink",
                1
        );
    }
```

### 3.5 ByNewPage — `openNewTab` obrigatório

Todo `getLawyer` de uma classe ByNewPage **deve** chamar `this.openNewTab(lawyer)` e sempre capturar o retorno em `link`:

```java
String link = this.openNewTab(lawyer);
```

A ausência dessa chamada invalida a classe. A captura do retorno é obrigatória mesmo que `link` não seja incluído no `Map` final.

## 5. Casos Especiais

**ByNewPage sem validação de role na 1ª página** — delegar a validação para um método auxiliar:
```java
@Override
protected Object getLawyer(WebElement lawyer) throws Exception {
    this.openNewTab(lawyer);
    WebElement content = driver.findElement(By.className("col-md-12"));

    String role = extractor.extractLawyerText(container, new By[]{By.("")}, "ROLE", LawyerExceptions::roleException);
    if (!siteUtl.isValidPosition(role, validRoles)) return "Invalid Role";

```

## 6. VCard

> **Use `VCard` apenas quando explicitamente solicitado nos dados da firma.** Nunca o inclua por padrão ou especulativamente.

Declare como campo privado da classe:

```java
// Padrões padrão — funciona para a maioria dos sites
private final VCard vCard = VCard.withDefaultPatterns();

// — ou — padrões customizados quando o site usa estrutura não-padrão
private final VCard vCard = new VCard(
    "X-EMAIL[^:\\r\\n]*:([^\\r\\n]+)",
    "X-TEL[^:\\r\\n]*:([^\\r\\n]+)"
);
```

Dentro de `getLawyer`, obtenha o `href` do link `.vcf` e chame `getSocials`:

```java
String vcardHref = lawyer.findElement(By.cssSelector("a.vcard")).getAttribute("href");

// Endpoint público (sem necessidade de sessão do browser):
String[] socials = vCard.getSocials(vcardHref);

// — ou — quando o endpoint exige cookies da sessão ativa:
String[] socials = vCard.getSocials(driver, vcardHref);

String email = socials[0];
String phone  = socials[1];
```

Retorna `String[]{ email, phone }` — strings vazias quando não encontrado.

## 7. Anti-padrões — Checklist Interno

> Antes de gerar cada classe, verificar todos os itens abaixo.

| # | Anti-padrão | Correção |
|---|---|---|
| 1 | Dados na subpágina quando disponíveis na 1ª (ByNewPage) | Extrair da 1ª página antes de chamar `openNewTab` |
| 2 | `this.openNewTab(lawyer)` sem capturar retorno | `String link = this.openNewTab(lawyer);` |
| 3 | Classe ByNewPage sem chamada a `this.openNewTab(lawyer)` em `getLawyer` | Toda classe ByNewPage **deve** chamar `openNewTab` — ver seção 3.5 |
| 4 | `new WebDriverWait(this.driver, Duration.ofSeconds(10))` | `MyDriver.wait.findElements(...)` |
| 5 | Lambda vazia `(e) -> ""` em `extractLawyerText` ou `extractLawyerAttribute`  | `LawyerExceptions::socialsException` (ou equivalente) |
| 6 | `By[] nameBy = {...}` declarado fora e passado como variável | `new By[] {...}` inline dentro do extractor |
| 7 | `extractor.extractLawyerText(driver, ...)` direto no driver | `WebElement container = driver.findElement(...);` → `extractor.extractLawyerText(container, ...)` |
| 8 | `VCard` incluído sem ser solicitado nos dados da firma | Remover — `VCard` só é usado quando explicitamente pedido (ver seção 6) |
