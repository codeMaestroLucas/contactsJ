# Prompt WebScrapping Java

Contexto do Projeto: Geração de classes Java (Selenium/Apache POI) para web-scraping de sites de advocacia baseados nas classes abstratas ByPage e ByNewPage.

1. Estrutura Obrigatória da Resposta
O output deve conter apenas os seguintes itens, nesta ordem:
    1. Cada firma gerada deve estar em um bloco de código separado para que eu possa copiar e colar cada uma.

    2. Comando touch tbm deve ser uma caixa de texto copiável: Uma única linha para criar todos os arquivos no diretório core/src/main/java/org/example/src/sites/to_test.

    3. Geração das Classes: Código completo dos scrappers, ordenados alfabeticamente.

    4. Bloco de Builders: Código para instanciação das firmas, agrupadas por Tipo de Classe e Continente, com no máximo 5 firmas por linha. Os builders estão em firms/src/main/java/org/example/src/utils/myInterface/ (ByNewPageFirmsBuilder.java e ByPageFirmsBuilder.java).

    * Parâmetros: O parâmetro WebElement em getLawyer e auxiliares deve se chamar obrigatoriamente lawyer.

private String getRole(WebElement content) throws LawyerExceptions {
    String role = extractor.extractLawyerText(content, new By[] {By.tagName("h3")}, "ROLE", LawyerExceptions::roleException);
    boolean validPosition = siteUtl.isValidPosition(role, validRoles);
    return validPosition ? role : "Invalid Role";
}
